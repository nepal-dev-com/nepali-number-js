# Getting help

| You have… | Go to |
|---|---|
| A question about how a function behaves | The [documentation](https://docs.nepal-dev.com/nepali-number): the [API reference](https://docs.nepal-dev.com/nepali-number/user-guide/latest/api) and its [limitations](https://docs.nepal-dev.com/nepali-number/user-guide/latest/api/limitations) |
| A question the documentation does not answer | [Discussions](https://github.com/nepal-dev-com/nepali-number-js/discussions) |
| A function that returns the wrong thing | A **bug** [issue](https://github.com/nepal-dev-com/nepali-number-js/issues/new/choose) |
| A wrong Nepali word or spelling | A **Nepali language** [issue](https://github.com/nepal-dev-com/nepali-number-js/issues/new/choose) |
| An idea for a new function or option | A **proposal** [issue](https://github.com/nepal-dev-com/nepali-number-js/issues/new/choose) |
| A vulnerability | [`SECURITY.md`](SECURITY.md). Never a public issue |

When you ask, include the call you made, what it returned, what you expected, and the version of
`nepali-number` you have installed.

This project is maintained by volunteers and makes no promise of response times. To help build it,
read [`CONTRIBUTING.md`](CONTRIBUTING.md).
